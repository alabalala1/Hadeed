# عرض صور التمارين والهوية الخضراء — 0.1.3

- زر «عرض الصورة المرفقة» داخل بطاقة التمرين المفتوحة أثناء الجلسة، وزر صورة في مكتبة التمارين عند وجود مرفق.
- عارض مستقل للصورة المحلية بحجم كبير، تكبير بإصبعين وسحب، إغلاق واضح، ورسالة عند فقدان الملف أو تعذر قراءته. تبقى مسودة الجولة والجلسة مفتوحتين.
- الجلسة تعرض صورة اللقطة المحفوظة، والمكتبة تعرض صورة تعريف التمرين الحالي. إذا لم تحمل الجلسة الجارية صورة وقت البدء، يعرض الزر الصورة المضافة لاحقًا للتعريف دون تغيير اللقطة أو سجل الجلسات المنتهية. لا تحميل من الإنترنت ولا تغيير لمخطط SQLite أو بيانات المستخدم.
- توحيد الألوان على جميع الشاشات: خلفية #EEF3F1، عنوان #123A32، أخضر #2A7552 وأزرار #BDF56A، ونص #132B2A. الأيقونات الأصلية الزرقاء تتلون أثناء العرض دون تعديل ملفات SVG أو أبعادها، وألوان التحذير والحذف تبقى دلالية.
- بطاقة «الحصة التدريبية اليوم» تملأ العرض بين الهوامش نفسها للبطاقات الأخرى. زر الإعدادات داخل البطاقة بدل حجز عمود خارجها.

التحقق المطلوب: التحليل وفحوص SQLite واختبار الواجهة وبناء APK في GitHub Actions، مع مراجعة لقطات اليوم والجدول والمكتبة وعارض الصورة والجلسة والإعدادات والخط المكبر.
