# الخطوة الرابعة — التطبيق المحلي المتكامل

## الوظائف

- تهيئة أول تشغيل: استخدام القائمة المؤكدة أو جدول مخصص. الترقيات لا تعيد التهيئة.
- اليوم: التدريب المستحق والتاريخ الفعلي وآخر زيارة واستكمال الجلسة والراحة بتاريخ اليوم أو سابق.
- جلسة مستقلة: لقطات الأسماء والخطط والصور، أداء كل جولة، أوزان كسرية أو صفر أو فارغة، وكارديو بالمدة.
- حفظ مسودة الإدخال محليًا، وحفظ الجولة بمعرّف ثابت، والتعديل والحذف وإعادة الترقيم والتخطي بسبب اختياري.
- آخر أداء مكتمل سابق بالمعرّف: أولوية نفس اليوم، مع التاريخ واسم اليوم وجميع الجولات. التعبئة لا تحفظ تلقائيًا.
- ملخص قبل الإنهاء مع تصريح الجلسة الجزئية. منع إكمال جلسة بلا أداء؛ تركها يحفظ الجولات ولا ينقل الدورة.
- تاريخ البدء المحلي لا يتغير عند عبور منتصف الليل. حدث واحد لكل تاريخ، والجلسة المتروكة تشغل تاريخها.
- دورة بمعرّفات مستقرة؛ الإنهاء يحرّكها مرة واحدة. إذا اختير بديل لليوم أثناء الجلسة يبقى البديل المختار.
- مؤقت جلسة من وقت البدء المحفوظ، ومؤقت راحة واحد بوقت نهاية أو رصيد توقف محفوظ؛ إيقاف واستئناف وإضافة وإعادة وتخطي.
- تشغيل الراحة تلقائيًا مغلق افتراضيًا، ولا يحدث بين مكونات السوبر سيت.
- سجل الجلسات والراحة، وبحث باسم تمرين أو يوم، وتصفية بالتاريخ واليوم والحالة. تصحيح جولات السجل بتأكيد دون تحريك الدورة.
- الإعدادات: kg/lb مع تخزين kg، راحة افتراضية للروابط الجديدة، صوت واهتزاز وتشغيل تلقائي وإذن إشعارات اختياري.
- ضبط مؤشر الدورة لأول يوم نشط بتأكيد، دون حذف السجل، ويُمنع أثناء جلسة مفتوحة.

## قاعدة البيانات والنسخ الاحتياطي

الإصدار 3 يضيف workout_sessions وsession_exercises وperformed_sets وcalendar_events وtimer_state.
جميع عمليات البدء والإنهاء والراحة تتم في معاملات، مع قيد جلسة جارية واحدة وتاريخ فريد.
التعريفات والخطط القديمة محفوظة. صور لقطات الجلسات لا تحذف عند تغيير صورة تعريف التمرين.

النسخة .hadeed ملف GZIP يحتوي JSON بإصدار تنسيق 1 ومخطط 3، والجداول والصور بصيغة Base64.
لا تتطلب مكتبات أرشيف أو خادمًا. الاختيار والحفظ عبر Android Storage Access Framework دون إذن عام للتخزين.
فحص محدود الحجم (64 MiB بعد فك الضغط) والإحالات والأنواع والصور في قاعدة مؤقتة قبل عرض المعاينة.
بعد التأكيد تُكتب الصور في مجلد جديد ثم تُستبدل الجداول بمعاملة؛ فشل المعاملة يبقي البيانات الأصلية.
الجلسة الجارية تستعاد قابلة للاستكمال من وقت بدايتها الأصلي؛ مؤقت الراحة لا يُصدّر ولا يُستعاد.
بعض الصور القديمة غير المرجعية قد تبقى محليًا؛ هذا مقصود لتجنب حذف ملفات أثناء التراجع أو فقدان لقطات.

## تنبيهات Android

MethodChannel محلي مع AlarmManager وBroadcastReceiver. لا يعتمد التنبيه على بقاء Dart Timer.
إلغاء/إيقاف/إضافة/إعادة/إنهاء الجلسة يحدّث التنبيه. يبقى SQLite مصدر الحالة، وSharedPreferences الأصلية مرآة لحمولة تنبيه الجهاز فقط.
إعادة التشغيل تعيد جدولة موعد مستقبلي؛ لا تعرض تنبيهًا قديمًا من النسخة الاحتياطية.
قنوات مستقلة للصوت والاهتزاز؛ رفض POST_NOTIFICATIONS لا يمنع التسجيل.
التنبيه الخلفي غير دقيق عمدًا لتجنب صلاحية منبه خاصة؛ يمكن أن يؤخره Doze أو توفير الطاقة.
المنع الإجباري للتطبيق يمنع تنبيه الخلفية حتى فتحه. الزمن الصحيح يظهر من البيانات عند العودة.
