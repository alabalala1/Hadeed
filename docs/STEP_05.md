# تحسينات تجربة الهاتف — 2026-10-04

## ملاحظات المستخدم

تظهر مساحة رمادية كبيرة بدل حقول الجولة عند فتح التمارين التالية؛ وزر الإنهاء مخفي أسفل القائمة، والهوية والبطاقات تحتاج ترتيبًا أقوى.

## التغييرات

- استبدال ExpansionTile في بطاقة الجلسة بعرض صريح يفتح بطاقة واحدة بالمعرّف الثابت؛ عرض النموذج محدد حتى داخل نافذة تصحيح السجل، دون قيود Flex غير محدودة.
- قائمة تمرير واحدة وبطاقات ذات ارتفاع ناتج عن المحتوى، دون ارتفاع ثابت ضخم أو عنصر بديل رمادي.
- زر إنهاء الجلسة ثابت خارج التمرير، وكذلك تأكيد الحفظ في الملخص؛ ترك الجلسة إجراء منفصل مع تأكيد.
- فصل الأهداف والجولات المحفوظة والنموذج؛ أرقام إدخال أكبر، الوزن والعدات متجاوران عند اتساع الشاشة وعموديان مع الخط الكبير أو الشاشة الضيقة.
- شرح وصورة التمرين داخل قسم اختياري، والمقارنة بالأداء السابق محفوظة.
- هوية كحلي #0D1733 وأزرق #2357F5 وبرتقالي #F97316، ونصوص أوضح وخلفية #F0F3FA؛ هذا طلب المستخدم الأحدث ويعدل لوحة المواصفات الأصلية دون تغيير قواعد البيانات.
- أيقونة باربل وحرف H أصلية بصيغة VectorDrawable، تشمل أيقونة Adaptive وMonochrome وبديل الأجهزة القديمة. مرجع الرسم assets/branding/hadeed-icon.svg.
- النسخة 0.1.1؛ لا تغيير لمخطط SQLite أو سجل المستخدم.

## التحقق

الاختبار المعدّل يفتح جميع بطاقات اليوم الأول، يسجل جولة في التمرين الثاني، يتحقق من عدم وجود ErrorWidget ومن محدودية ارتفاع النموذج وثبات زر الإنهاء، ثم ينهي الجلسة من الواجهة نفسها. يشمل شاشة 320×740 مع نص 1.8×، إضافة إلى فحوص قاعدة البيانات السابقة.
نتيجة التنفيذ وبناء APK تُسجّل بعد اكتمال GitHub Actions. اختبار هاتف المستخدم مطلوب للتأكد من زوال العطل الظاهر في الصورة على جهازه.

التوقيع لا يزال للتطوير؛ صدّر نسخة احتياطية قبل إزالة النسخة السابقة إذا رفض Android تحديثًا بسبب اختلاف المفتاح.
