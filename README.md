# Hadeed — حديد

تطبيق Flutter للأندرويد باللغة العربية، يعمل محليًا دون حساب أو خادم.

## المنفذ حاليًا

- البنية الأساسية لـFlutter وAndroid.
- مكتبة التمارين وفق Figma: بحث وتصنيف وحالات فارغة.
- إضافة التمارين وتعديلها، مع نوع قياس للتكرارات أو المدة.
- اختيار صورة من الهاتف أو الكاميرا، ونسخها داخل التطبيق.
- أرشفة التمارين واستعادتها.
- حفظ مباشر في SQLite واستعادة البيانات عند فتح التطبيق.
- خط Cairo وأيقونات Figma محلية.

المكتبة تبدأ فارغة وفق اختيار المستخدم، إلى أن يرسل قائمة التمارين.
إدارة الأيام والخطط والجلسات والسجل ستضاف تدريجيًا.

## التشغيل

ثبّت Flutter stable (3.44 أو أحدث)، مع Android SDK وJDK 17:

```sh
flutter pub get
flutter analyze
dart run tools/check_repository.dart
flutter run
```

إعدادات Android مبنية على قالب Flutter 3.47.5. المعرّف الأولي
`ye.hadeed.hadeed` والتوقيع الحالي للتطوير فقط.

فحص مصدر Dart واختبارات SQLite المحلية نجحا. بناء APK والمقارنة البصرية
على Flutter واختبار الجهاز لم تُنفّذ بعد. التفاصيل في `docs/STEP_02.md`،
والدليل الكامل في `docs/GYM_APP_SPEC.md`.
