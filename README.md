# Hadeed — حديد

مشروع تطبيق Flutter للأندرويد باللغة العربية.

## الخطوة الأولى: البنية الأساسية

- نقطة تشغيل التطبيق في `lib/main.dart`.
- إعداد التطبيق والعربية واتجاه RTL في `lib/app/app.dart`.
- إعداد المظهر الأساسي في `lib/core/theme/app_theme.dart`.
- مجلدات مستقلة للميزات والمنطق والتخزين المحلي.
- ملفات Android وGradle Wrapper مضمّنة.

واجهة التشغيل الحالية تعرض اسم التطبيق فقط. تصاميم Figma والوظائف وقاعدة البيانات ستضاف في الخطوات التالية.

## التشغيل

ثبّت Flutter stable (3.44 أو أحدث)، مع Android SDK وJDK 17.

```sh
flutter pub get
flutter analyze
flutter run
```

إعدادات Android مبنية على قالب Flutter 3.47.5. معرّف التطبيق الأولي هو `ye.hadeed.hadeed`، والتوقيع الحالي للتطوير فقط.

## التحقق

تم فحص تنسيق Dart وتحليل المصدر مباشرة بأداة Dart، والتحقق من ملفات Android وGradle Wrapper. لم يُنفّذ بناء APK أو تشغيل على جهاز في هذه البيئة.
